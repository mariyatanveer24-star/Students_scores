# Students_scores
I finished a small Power BI project this week using exam scores. I wanted to see what goes along with higher results.  I cleaned the data in Power Query, built a small model, wrote the DAX measures, and used a field parameter and the Key influencers visual. This is a practice dataset, so I treat the results as patterns and not as proof of causes.
 Student Exam Scores: Power BI Analysis
I analyzed exam scores of 1,000 students to see what goes along with higher 
results: test preparation, gender, parental education, and lunch type.

## Questions
1. What are the average scores, and how many students score 60 or more?
2. Do students who completed test prep score higher?
3. Do scores differ by gender and subject?
4. How do scores change with parental education and lunch type?

## How I built it
Power Query (cleaning, unpivot), a small star-schema model, DAX measures, a 
field parameter, conditional formatting, and the Key influencers visual.

## Notes- These are patterns, not causes.- The 60 pass mark is my own choice.- This is a small practice dataset.
Data: Students Performance in Exams, Kaggle.
